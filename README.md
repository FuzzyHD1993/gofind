# gofind

Индексатор и поисковик по медиатеке NAS: SQLite + FTS5, частичный поиск по имени и пути, TUI на bubbletea.

## Установка

```sh
go build -o gofind ./cmd/gofind
```

## Использование

```sh
# проиндексировать библиотеку (по умолчанию /mnt/nas/root/FuzzyHD)
gofind index

# инкрементальное обновление + удаление пропавших файлов
gofind index -prune

# поиск
gofind search matrix
gofind search "Матр" -limit 20
gofind search matrix -json

# интерактивный поиск
gofind tui
```

По умолчанию база: `~/.local/share/gofind/gofind.db`.

## Как устроено

- `internal/db` — схема `files` + внешняя FTS5-таблица `files_fts` с триггерами, WAL, батч-апсерт по 1000.
- `internal/index` — обход `filepath.WalkDir`, пропуск служебных файлов и каталогов, инкрементальное обновление по `size`/`mtime`.
- `internal/search` — FTS5 `MATCH` с префиксами по токенам, `bm25` для ранжирования, LIKE-фолбэк для подстрок.
- `internal/ui` — bubbletea: ввод с дебаунсом 80 мс, список результатов, `Enter` открывает папку через `xdg-open`.

## Замеры (реальная библиотека, CIFS)

- обход: **215 854 файла за 2 мин 23 с** (~1 500 файлов/с), база — 99 МБ;
- 10 000 файлов — 4,1 с; 100 000 — 89 с; 200 000 — 137 с;
- поиск по реальной базе: **3–6 мс** на запрос (процесс целиком, включая открытие SQLite);
- промах FTS (нет совпадений) уходит в LIKE-фолбэк: ~140 мс на 215 тыс. строк.
